What do these numbers mean?
Position (x, y)
Metres from the 0,0 corner (anchor A2): X along the width, Y along the depth, the same as the floor grid.
Margin of error (±)
The tracker's own uncertainty, 1σ. About 2 out of 3 positions fall inside this radius. Drawn around the tag to scale.
Range
Distance measured by UWB between the tag and one anchor, in 3D.
Range offset (b)
Extra distance every range carries because of the DW1000 antenna delay (about 75–100 cm). Removed by the static calibration, or estimated automatically while there is none.
Anchor offset (d)
How much one anchor reads more or less than the others. Taken from the static calibration (Setup) once it is applied; until then learned while the trolley moves. Above 20 cm = that anchor's position in the scene is probably wrong.
Residual
Measured range minus the range expected from the position and offsets. Large or ✕ = blocked / reflected signal or wrong anchor position.
LOS / NLOS
Clear line of sight / blocked by an obstacle drawn in the scene.
Confidence
1 / (1 + margin of error in m). Navigation receives it as "quality".
standing / moving
Standing: the tracker's zero-velocity mode is on (the speed stayed below 0.2 m/s for 0.4 s). The trolley's velocity is held at 0 and a range that comes in too long (a person in the way) is ignored, so the position stays put. It ends as soon as the ranges show movement.
HOLD
Fewer than 3 anchors heard in 1.5 s: the last good position is kept and marked not valid, so navigation does not steer on a guess.
Accuracy / precision
Accuracy: how close to the true position. Precision: how tightly positions cluster when still.
Mean error, RMSE, CEP50 / CEP95
Mean error: average distance to the true point. RMSE: large errors count more. CEP: radius holding 50 % / 95 % of the positions.

Only what has to be measured in your room is set here: the room, the anchor positions (click an anchor in the 3D view, or drag it) and the tag height, then the calibration below. The tracking algorithm itself is fixed.

1 · Room metres

Ranges are measured in 3D and projected onto the floor, so a wrong tag height shifts every position.

2 · Calibration & static test

Every DW1000 adds its own few centimetres to each range. Put the tag still on a spot you measured with the laser meter (same origin as the anchors, not on an anchor), enter its X/Y and press Measure. Do this at 2–4 spots, then press Apply: the tracker then takes each anchor's offset from the calibration instead of learning it. To test the accuracy afterwards, untick "keep" and measure at another spot.
